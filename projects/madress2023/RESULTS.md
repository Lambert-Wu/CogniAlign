# madress2023 结果

这份文档回答一个问题：**把 madress-2023 的 AD 检测方法从英文搬到中文，效果到底如何？卡在哪？**

> **论文**：Tamm, Vandenberghe, Van Hamme, *Cross-Lingual Transfer Learning for
> Alzheimer's Detection From Spontaneous Speech*, ICASSP 2023
> （参考实现 [`lcn-kul/madress-2023`](https://github.com/lcn-kul/madress-2023)）。
> **任务**：输入一段谈话录音，判断说话人是 **AD（阿尔茨海默）/ CN（健康）**。
> **语言对**：英文训练 → 中文测试。
> **复现代码**：本目录（协议细节见 `README.md`）。
>
> 结果文件：`logs/results_mean.json`（推荐）、`logs/results_main.json`；
> 报告 `logs/report_mean.md` / `report_main.md`。最后更新：2026-10-05。

---

## 0. 先看结论（TL;DR）

| # | 实验 | 中文测试上的表现 | 一句话解读 |
|---|---|---|---|
| 1 | **跨语言少样本**（论文协议） | acc **0.669** / AUC **0.761** | 英文预训练 + 中文少量样本微调，确实能做 |
| 2 | **零样本**（不微调） | acc **0.636** / AUC **0.724** | 不微调也高于随机，但微调只多赚一点点 |
| 3 | **纯中文**（完全不碰英文） | acc **0.92** / AUC **0.97** | 中文数据本身很好分；之前差是**样本太少** |

> 随机猜测 AUC = 0.5；"多数类"基线 acc = 0.569（中文测试 72 条里 CN 占多数）。
> 实验 3 用的是中文 80 条内部划分，和实验 1/2 不是同一套数据，见下文说明。

## 1. 先看名词（不明白再看正文）

| 名词 | 意思 |
|---|---|
| **acc（准确率）** | 判对的比例。0.569 = 什么都不学、全猜 CN 就能到的分数。 |
| **AUC** | 排序质量：把 AD 排在 CN 前面的能力。0.5 = 随机，1.0 = 完美；不受类别不平衡影响，比 acc 更可靠。 |
| **8-shot** | 目标语言只给 8 条带标签样本（中文这里就是 `train_uids0` 那 8 条）。 |
| **零样本 / 少样本** | 零样本 = 不微调，英文模型直接测中文；少样本 = 用少量中文样本微调后再测。 |
| **参数平均** | 论文做法：把 2 折微调出来的两份权重逐元素平均，当作一个模型（§2.5）。 |
| **LLD** | openSMILE 里 eGeMAPS 特征集的**帧级**声学参数，共 **25 个**：响度、音高、jitter/shimmer、谐噪比、MFCC1–4、共振峰 F1–F3 等。每条录音切 10 段 → 每样本是 `(10, 25)` 的张量。 |
| **"LLD 均值" vs "首帧"** | 每段音频有很多时间帧，怎么压成一个 25 维向量：**均值**=对该段所有帧取平均（本移植默认、推荐）；**首帧**=只取第 0 帧（忠实复现参考代码的 `y[0,:]`，其实是个 bug）。 |

详细设置见第 5 节。

## 2. 实验 1 & 2：跨语言（英文预训练 → 中文）

**做法**：英文 235 条预训练（跑 5 个随机种子，用中文 8 条挑最好的）→ 在中文 8 条上做
2 折混合批次微调 → 参数平均 → 在中文测试 72 条上评测；整套重复 5 次。
**不微调（实验 2）** 就是直接用预训练模型测中文。

5 次流程的 mean±std（多数类基线 acc = 0.569）：

| 特征聚合 | 方式 | acc | AUC | F1 | bal_acc |
|---|---|---|---|---|---|
| **LLD 均值**（推荐） | **微调（少样本）** | **0.669±0.039** | **0.761±0.065** | 0.535±0.068 | 0.643±0.039 |
| LLD 均值（推荐） | 零样本（不微调） | 0.636±0.064 | 0.724±0.085 | 0.539±0.081 | 0.619±0.061 |
| 首帧（忠实参考） | 微调（少样本） | 0.611±0.044 | 0.650±0.029 | 0.507±0.093 | 0.595±0.049 |
| 首帧（忠实参考） | 零样本（不微调） | 0.572±0.060 | 0.637±0.083 | 0.527±0.040 | 0.571±0.043 |

**逐次分数**（LLD 均值聚合，看方差有多大）：

- 微调 acc `0.611 / 0.639 / 0.708 / 0.708 / 0.681`，AUC `0.673 / 0.730 / 0.839 / 0.730 / 0.834`
- 零样本 acc `0.583 / 0.625 / 0.694 / 0.556 / 0.722`，AUC `0.692 / 0.714 / 0.781 / 0.591 / 0.841`

**怎么读**：

- 换"LLD 均值"比原来的"首帧"明显更好（这就是为什么默认用它）。
- 微调相对零样本只提升约 **+0.03 acc / +0.04 AUC**，而单次之间本身就能差 0.1 以上 —— 所以
  **"少样本微调带来多大好处"在这份数据上并不显著**。
- 迁移有信号（零样本 AUC 0.72 ≫ 0.5），但**方差很大**：有一次零样本直接掉到 AUC 0.475（比随机还差）。
- ⚠️ 口径：这里的"零样本"仍用中文 8 条验证 loss 挑 seed，比严格意义上没看过目标语言略乐观。

## 3. 实验 3：纯中文，80 条分层 5 折（完全不碰英文）

**为什么做**：实验 1/2 的瓶颈到底是"英文迁移没用"，还是"目标样本太少（只有 8 条）"？
于是把中文**全部 80 条**拿出来，自己分训练/验证，从零训练一个模型。

**怎么分**：用仓库 `make_splits.py` 为"中文自己训/测"准备的分层规则
`StratifiedKFold(5, shuffle=True, random_state=42)`，切成 5 折，每折 **64 条训练 / 16 条验证**，
按 AD/CN 分层。**随机初始化、不用任何英文**；训练放 GPU、全批；每折跑 5 个种子。

| 训练轮数 | 验证 acc | 验证 AUC |
|---|---|---|
| 100 | 0.900±0.088 | 0.966±0.038 |
| 300 | 0.917±0.080 | 0.970±0.037 |
| 1000 | **0.920±0.082** | **0.971±0.036** |

- 每折 acc ≈ `[0.85, 0.91, 0.85, 0.99, 1.00]`；每折多数类基线 0.562。
- **不是挑出来的**：按验证 loss 早停 vs 固定轮数不选点，结果**完全一样**（300 轮两栏都是 0.917 / 0.970）。
- **不是数据上限**：同样的模型如果用小批量 + 每轮重复读盘，只有 0.775（100 轮）/ 0.812（300 轮）——
  那是没训够；全批训练后立刻到 0.90+。

## 4. 综合结论

1. **中文数据本身高度可分**：64 条中文训练样本，一个从零训练的小 eGeMAPS 模型就能到 AUC ~0.97。
   实验 1/2 只有 0.72–0.76，差距主要来自**监督样本量**。
2. **英文预训练 + 跨语言迁移在本数据上没有被证明是必需的**：零样本 0.724 说明"有信号"，
   但相对中文直接训练没有明显优势；在 8 条预算下，迁移与"纯中文全 8 条训够"（0.788）大致相当。
3. 这与兄弟项目 `projects/AutomatedSpeech/` 的结论方向一致：**中文内部有效（0.911），跨语言 0-shot 基本不迁移**，
   根因更可能是**任务/域不可比**（英文是单一 Cookie Theft 看图说话；中文是多任务、被截到 60 秒），
   而不是语言本身。

## 5. 详细设置

- **数据**：英文 ADReSSo train 235 条（train 188 / val 47）；中文 test 80 条
  （其中原生 8-shot `train_uids0` 8 条 / test `val_uids0` 72 条；AD 35 / CN 45）。
- **模型**：论文网络（隐层 12、dropout 0.2、二分类）；AdamW，lr 3e-3，warmup 100，
  weight decay 1e-2，30 epoch，batch 32；混合批次每 5 个样本注入 1 个目标语言样本。
- **协议**：英文预训练 5 个种子（中文 8 条验证、取 val loss 最低）→ 中文 8 条内 2 折混合批次微调
  → 参数平均 → 中文 72 条预测；整套重复 5 次。
- **与论文的差异**：去掉 age/gender/education 协变量（本数据没有）；目标语言是中文而非希腊语；
  不做英文类别平衡（没有 MMSE 分数）。
- **聚合口径**：参考实现取每段 LLD 的**首帧**（`y[0,:]`），本移植默认改为**每段 LLD 均值**
  （`--agg mean`）。同语言 5 折 AUC：英文 0.571 → 0.688，中文 0.872 → 0.960。

---

## 6. 局限（别过度解读）

- 中文内部 5 折是**单个随机划分**（seed 42），每折只有 16 条验证；5 个种子只压了模型随机性，
  **没压划分随机性**（折间 acc 0.85–1.00）。
- 划分**未按说话人分组**（仓库划分工具也没做）。80 条 uid 都是独立数字、无任务后缀，看起来一人一条；
  若实际存在同一人多条，分数会偏高。
- 实验 1/2 与实验 3 **目标监督量不对等**（前者每折 4 条 + 英文，后者 64 条），不是同一预算下的对比。
- 样本量很小（中文 80，验证折 16），**不要把 ±0.08 量级的差异当作显著**。

## 7. 怎么复现

```bash

cd projects/madress2023 && python report.py --tag mean
```
