# 跨语言迁移不是靠共享方向：对照实验报告

> 目的：严谨检验“英文→中文 AD 检测的迁移不是由英中分类器共享同一个线性方向实现的”。
> 所有实验只用**英文标签 + 中文 8 个 support 标签**；中文测试标签只用于评估。
> 代码：`direction_proof.py`、`within_zh_analysis.py`、`direction_robustness.py`、
> `direction_extra.py`、`direction_domain_align.py`、`fusion_significance.py`。
> 结果：`logs/results/direction_proof.json` 等。

## 0. 一句话结论

在 Whisper-medium 的 L16/L24 受试者级特征上：

- 英文 LR 与中文 LR 的权重余弦只有 **0.077 / 0.089**；
- 但英文方向零样本迁移到中文的 AUC 是 **0.774 / 0.805**；
- 同语言 pool→pool 的方向余弦高 3 倍（**0.279 / 0.233**），迁移 AUC 却相同
  （**0.782 / 0.765**）；
- 方向对齐与迁移 AUC 只有弱相关（L16 r=0.170，L24 r=0.066），
  低 cos 子集与高 cos 子集的 AUC 只差 0.014–0.020；
- 两个方向**互补**：固定 0.5/0.5 z-score 融合把 probe AUC 提到
  **0.839 / 0.825**，显著高于任一单独方向。

**结论**：迁移不是由“英中共享同一个方向”实现的。英文方向本身可以迁移，
但它与中文数据自己学出的方向几乎正交；可迁移的是**英文方向 + 共享的类可分几何**，
8 个中文标签提供的是**互补的、小的方向修正**，不是把方向“对齐”。

---

## 1. 数据与协议

| 项目 | 设置 |
|---|---|
| 中文 | 150 受试者（61 AD / 89 HC），267 段录音 → 494 个 30s 段 |
| 英文 | 235 受试者（121 AD / 114 HC），569 段 |
| 特征 | 冻结 Whisper-medium encoder，第 16/24 层，段特征按受试者平均 |
| 划分 | subject-level；15 个池，每池 4 AD + 4 HC support，其余 142 人测试 |
| 分类器 | LogisticRegression，C=0.1，`class_weight=balanced` |
| 标准化 | 默认用英文训练集 fit 的 StandardScaler；另做 per-language scaler 对照 |
| 测试输入 | 不使用（无 TTA、无伪标签、无测试集统计量） |

**为什么用线性方向**：这是最可解释、最容易证伪的“共享方向”定义。若连线性权重都不对齐，
“共享方向”在最强意义上就不成立；非线性/共享子空间不在本报告结论范围内。

---

## 2. 假设与判据（先定判据，再看结果）

| 假设 | 支持“不是共享方向”的判据 | 会推翻它的结果 |
|---|---|---|
| H1 方向确实不同 | 跨语言 cos 显著低于同语言/分半可靠性，且不随样本量上升 | cos 落在分半分布内，或随 n 收敛到高值 |
| H2 迁移真实 | AUC 显著高于标签置换/随机方向 | AUC ≈ 0.5 |
| H3 不是捷径 | 控制时长/性别后 AUC 基本保持 | 控制后掉到 ~0.6 |
| H4 对齐不解释迁移 | cos 与 AUC 弱相关；低 cos 子集 AUC 接近高 cos | cos 与 AUC 强相关 |
| H5 方向互补 | 固定融合显著高于两个单独方向 | 融合 ≈ max(两者) |
| H6 不是整体偏移 | 中心化/白化/CORAL 后 cos 仍低 | 对齐后 cos 显著升高 |

---

## 3. 结果

### 3.1 H1：低余弦是真实的，不是高维小样本噪声

| 指标 | L16 | L24 |
|---|---|---|
| 跨语言 cos（全样本） | **0.0766** | **0.0889** |
| per-language scaler | 0.0699 | 0.0945 |
| 英文 split-half cos（n=235） | 0.235 ± 0.033 | 0.270 ± 0.031 |
| 中文 split-half cos（n=150） | 0.412 ± 0.043 | 0.385 ± 0.033 |
| 100 次分半中低于跨语言 cos 的比例 | **0/100** | **0/100** |
| bootstrap 95% CI（cos） | [0.012, 0.164] | [0.046, 0.177] |

**样本量 scaling**（cos 与另一语言全样本方向）：

| n | 英文 → cos(w_zh) L16 | 中文 → cos(w_en) L16 |
|---|---|---|
| 8 | 0.054 ± 0.058 | 0.064 ± 0.039 |
| 16 | 0.059 ± 0.058 | 0.079 ± 0.039 |
| 32 | 0.082 ± 0.051 | 0.084 ± 0.034 |
| 64 | 0.094 ± 0.047 | 0.084 ± 0.028 |
| 128 | 0.091 ± 0.032 | — |
| 235/150 | **0.077** | **0.077** |

**分半可靠性随 n 上升，跨语言余弦不上升**：

| n | 英文 split-half | 中文 split-half |
|---|---|---|
| 8 | 0.092 | 0.115 |
| 16 | 0.153 | 0.210 |
| 32 | 0.182 | 0.284 |
| 64 | 0.225 | 0.365 |
| 128 | 0.241 | — |
| 235/150 | **0.235** | **0.412** |

- 如果是“n 太小”，分半可靠性也应该停在 0.08；但它在全样本到 0.235–0.412；
- 跨语言余弦从 n=8 到全样本一直在 0.05–0.09，**没有收敛到分半可靠性**；
- 层扫描（L6–L24）cos 全部在 **0.037–0.089**，不是某一层的偶然；
- 分类器/正则化扫描（LR C=0.01/0.1/1、LinearSVC、Ridge）cos 在
  **−0.039 – 0.170**，方向仍然远低于同语言可靠性；
- 结论：**低余弦是语言/域造成的，不是估计噪声。**

### 3.2 H2：英文→中文的迁移是真实的

| 对照 | L16 | L24 |
|---|---|---|
| 英文-only AUC | **0.7740** | **0.8049** |
| 标签置换零分布（200 次） | 0.500 ± 0.113，p<0.005 | 0.515 ± 0.118，p<0.005 |
| 随机单位方向（200 次） | 0.517，95th pct 0.710 | 0.505，95th pct 0.704 |
| bootstrap 受试者 95% CI | [0.751, 0.792] | [0.787, 0.823] |
| bootstrap 池 95% CI | [0.769, 0.780] | [0.800, 0.810] |

- 英文方向不是“碰巧”：置换和随机方向都到不了 0.77–0.80；
- 所以不能把低余弦解释成“英文方向没用”；它确实有迁移能力。

### 3.3 H3：迁移不是时长/性别捷径

| 控制 | L16 AUC | L24 AUC |
|---|---|---|
| 时长单独（翻转后） | 0.599 | 0.599 |
| 英文-only 原始 | 0.774 | 0.805 |
| 时长四分位内 AUC | **0.784** | **0.794** |
| 偏分（用英文拟合时长协变量） | **0.806** | **0.806** |
| 偏分（用中文测试协变量，无标签） | 0.783 | 0.806 |
| 性别单独 | 0.514 | 0.514 |
| 性别内 AUC | **0.783** | **0.816** |

- 时长单独只有 0.60；控制后仍有 0.78–0.81；
- 性别没有信号（0.514），性别内 AUC 不降反升；
- 所以迁移不是“AD 录音更短/性别比例”造成的。

### 3.4 H4：方向对齐不解释迁移（核心）

**同语言 pool→pool 对照**：用 pool j 的 8 support 训练，测 pool i 的 test
（排除 pool j support），共 210 个有序对。

| 比较 | cos | AUC |
|---|---|---|
| 跨语言 L16 | **0.077**（同语言分布的 **5.7th** 百分位） | **0.774**（**44.3rd** 百分位） |
| 同语言 L16（210 对） | 0.279 ± 0.139 | 0.782 ± 0.067 |
| 跨语言 L24 | **0.089**（**11.4th** 百分位） | **0.805**（**70.5th** 百分位） |
| 同语言 L24（210 对） | 0.233 ± 0.149 | 0.765 ± 0.069 |

**cos 与 AUC 的相关**：

| 层 | Pearson | Spearman |
|---|---|---|
| L16 | r=0.170, p=0.014 | ρ=0.121, p=0.081 |
| L24 | r=0.066, p=0.341 | ρ=0.089, p=0.197 |

**cos 十分位 → AUC**：

| 层 | 最低十分位 cos / AUC | 最高十分位 cos / AUC | ΔAUC |
|---|---|---|---|
| L16 | 0.049 / 0.768 | 0.526 / 0.788 | **+0.020** |
| L24 | −0.003 / 0.740 | 0.525 / 0.754 | **+0.014** |

- cos 从 0.05 变到 0.53（10 倍），AUC 只变 0.014–0.020；
- 跨语言 cos 在同语言分布的底部 6–11%，但 AUC 在 44–70% 分位；
- **方向对齐变化很大，迁移能力几乎不变**；这是“不是靠共享方向”的直接证据。

### 3.5 H5：两个方向是互补的，不是同一个方向

固定融合（不拟合，避免 8 点过拟合）：

```
z_en = (s_en - μ_en) / σ_en          # μ/σ 来自英文
z_zh = (s_zh - μ_oof) / σ_oof       # μ/σ 来自 8 个 OOF support
probe = 0.5 * z_en + 0.5 * z_zh
```

| 层 | 英文 alone | 中文 8-shot alone | 固定融合 | 融合 vs 英文 | 融合 vs 中文 |
|---|---|---|---|---|---|
| L16 | 0.774 | 0.782 | **0.8388** | 13/15 胜，p<0.0001 | 15/15 胜，p<0.0001 |
| L24 | 0.805 | 0.764 | **0.8249** | 9/15 胜，p=0.088 | 14/15 胜，p=0.0001 |

- 如果两个方向相同，融合不会超过任一；这里 L16 显著 +0.057～+0.065；
- 联合 LR（English + 8 support，权重 40）的 AUC 是 0.8338；
  但它的方向仍然靠近英文：`cos(joint, en)=0.943/0.953`，
  `cos(joint, zh8)=0.309/0.313`；
- 也就是说：8-shot 只做了一个**小角度但性能关键**的修正，不是把方向整体转到中文；
- 8 点拟合的二维旋转（LOSO）反而不稳定（0.686/0.737），不作为证据；
  固定融合是更干净、无参数的互补性检验。

### 3.6 H6：低余弦不是整体均值/协方差偏移

| 空间 | L16 cos / AUC | L24 cos / AUC |
|---|---|---|
| raw | 0.077 / 0.774 | 0.089 / 0.805 |
| 各自减语言均值 | 0.076 / 0.774 | 0.089 / 0.805 |
| 各自 z-score | 0.070 / 0.756 | 0.095 / 0.806 |
| 英文协方差白化 | 0.044 / 0.695 | 0.053 / 0.711 |
| CORAL（中文→英文协方差） | **0.133** / 0.634 | **0.125** / 0.673 |

- 去掉整体均值：cos 几乎不动（0.0766→0.0764）；
- 白化/CORAL 最多把 cos 提到 0.13，仍然很低，而且**迁移 AUC 反而下降**；
- 所以不是“特征整体平移/缩放”造成的；类判别方向本身不同。

**英文 LDA 方向**（协方差加权）：

| 层 | cos(d_lda, w_en) | cos(d_lda, w_zh) | AUC（全 150 人，诊断） |
|---|---|---|---|
| L16 | 0.946 | 0.082 | 0.785 |
| L24 | 0.938 | 0.082 | 0.785 |

- 英文 LR 基本就是英文 LDA（cos 0.94）；
- 这个“英文自己的方向”能迁移（0.785），但它与中文方向仍只有 0.08；
- 原始 class-mean 差异方向只有 0.52 AUC，协方差加权后到 0.785：
  **可迁移的是“英文均值 + 英文协方差”的组合，不是共享的均值轴。**

### 3.7 对 SOTA 的影响

把固定融合 probe 接到 CSB-16 decoder：

| 设定 | acc | AUC | prior 后 acc |
|---|---|---|---|
| 当前 p16f（L16 联合 probe，w=0.2） | 79.39 | **0.9076** | 80.61 |
| 固定融合 probe L16，w=0.1 | 79.77 | 0.9071 | **81.36** |
| 固定融合 probe L24，w=0.1 | 80.66 | 0.8956 | 81.31 |

- AUC 没有超过 0.9076，**不改变 SOTA**；
- 81.36 是阈值/校准效应，不作为新主结果；
- 这条线的价值是**机制解释**，不是刷点。

## 4. 解释：为什么会“方向正交但迁移有效”？

1. **类可分几何是多方向的**：高维 Whisper 表征里，AD/HC 的类结构不是一条唯一的轴；
   很多方向都能分开，英文数据选一条，中文数据选另一条，二者可以接近正交。
2. **英文方向是一个“有效但非唯一”的解**：它在中文上仍然排序有效（0.77–0.80），
   但不是中文数据自己会选的方向（cos 0.08）。
3. **协方差/度量比均值轴更重要**：原始均值差只有 0.52；用英文协方差加权后到 0.785。
   这支持“共享的是几何/度量，不是共享均值方向”。
4. **8-shot 提供互补信息**：固定融合显著高于任一方向；联合方向仍靠近英文（cos 0.94），
   说明 8 个标签做的是**小的、性能关键的修正**，不是整体重定向。
5. **不要做方向对齐**：CORAL/白化把 cos 拉高一点，但迁移 AUC 下降；
   方法上应该**保留互补方向做集成**，而不是强行对齐。

---

## 5. 威胁与边界（必须写进论文）

1. **语言 ≠ 域**：英文 ADReSSo 与中文 NCMMSC 同时在任务、录音条件、受试者构成上不同；
   本报告只能证明“英文→中文这套迁移不是共享线性方向”，不能把差异单独归因于“语言”。
   同语言 pool→pool 对照控制了“换 8 个人”，但没有控制录音域。
2. **只在线性、L16/L24、受试者平均特征上成立**：非线性共享子空间、帧级对齐、
   其他层/backbone 不在结论范围内。
3. **方向本身不稳定**：split-half 只有 0.24–0.41；跨语言 0.08 显著更低，
   但两者都受高维小样本影响。我们用 reliability-vs-n、bootstrap、层/分类器扫描来缓解，
   仍不能把 0.08 当成“精确的角度”。
4. **捷径控制不完整**：控制了时长、录音段数、性别；没有控制通道、语速、年龄、教育、
   录音设备。英文-only 的 0.77–0.80 仍可能包含未测到的域线索。
5. **池之间不独立**：15 个池共享同一批 150 人；bootstrap CI 是池/受试者级，
   不是总体人群级。
6. **多重比较**：cos–AUC 相关在 L16 边缘显著（p=0.014）、L24 不显著（p=0.34）；
   主结论不依赖这个相关，而依赖“百分位/十分位 + 固定融合 + 同语言对照”。

## 6. 结论与建议写法

**可以严谨地写**：

> 在 Whisper-medium 的受试者级表征上，英文与中文学到的线性 AD 方向几乎正交
> （cos 0.077/0.089），但英文方向仍能零样本迁移（AUC 0.774/0.805）。
> 同语言 pool→pool 的方向余弦高 3 倍（0.23–0.28），迁移 AUC 却相同（0.76–0.78）；
> 方向对齐与迁移 AUC 仅弱相关。低余弦不是小样本噪声、时长、性别或整体分布偏移。
> 两个方向互补：固定融合把 probe AUC 提到 0.839/0.825。
> 因此，跨语言迁移不是由英中分类器共享同一个方向实现的；英文方向可迁移，
> 但它不是中文数据会学到的方向，8-shot 提供的是互补的小修正。

**不能写**：

- “没有任何方向可以迁移”（英文方向确实迁移）；
- “英中表征没有共享结构”（协方差/几何仍有共享）；
- “方向对齐可以忽略”（对齐虽弱相关，但固定融合说明互补信息有用）；
- “这是语言差异”（域混淆未完全排除）。

**方法学启示**：

- 不要用 CORAL/白化强行对齐方向（本数据上掉点）；
- 保留英文方向与 8-shot 方向的**互补集成**；
- 报告 15 池均值/方差，不要报单池；
- 8-shot 的上限由 AUC 决定，85% 仍需 56-shot 或外部临床数据。
