# ---------------------------- 深度学习框架 ----------------------------
# 全项目的张量与模型（projects/cognialign/networks/model.py / dataset/dataset.py / train.py）
torch==2.14.0+cu126
# ⚠️ 这里**没有 torchaudio，是故意的**：
#   torchaudio 2.9 起默认后端换成 TorchCodec，而 TorchCodec 必须依赖外部 FFmpeg 库。
#   没有 ffmpeg 的机器上 torchaudio.load() 直接抛 "Could not load libtorchcodec"，
#   而且 backend="soundfile" 之类的参数会被忽略（换后端也救不了）。
#   本项目三条音频分支统一用 librosa 读音频（见下）。
#   换句话说：删掉 torchaudio 是为了少一个"版本必须和 torch 严格配套"的坑。
